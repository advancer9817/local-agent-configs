# Codex Agent Instructions

## lmmcp / mcore 记忆系统

你有访问 `local_memory` / `mcore` MCP server 的权限（http://127.0.0.1:8318/mcp）。

**每次收到用户问题时，在回答之前必须执行以下步骤：**

1. 调用 `memory_context` 工具，task 参数设为用户问题，token_budget=1200
2. 调用 `memory_search` 工具，query 参数设为用户问题，limit=5
3. 如果返回了相关记忆，将其作为背景知识参考，在回答中体现

**回答结束后，执行以下步骤：**

4. 调用 `memory_ingest` 工具，将本轮 user 问题和 assistant 回答作为 messages 传入，user_id="advancer"

这样可以确保你的回答基于历史上下文，并且每次对话都会积累到记忆库中。

## 工具调用示例

查询记忆：
```
memory_context(task="用户的问题", token_budget=1200)
memory_search(query="用户的问题", limit=5)
```

ingest 回答：
```
memory_ingest(messages=[
  {"role": "user", "content": "用户问题"},
  {"role": "assistant", "content": "你的回答"}
], user_id="advancer")
```

## 注意事项

- 记忆中枢边车服务运行在 http://127.0.0.1:8318/mcp
- 如果 memory_context 返回空或服务不可用，直接回答，不要报错
- ingest 步骤是后置的，不影响回答质量，失败时静默跳过

## 交互与沟通规范（空行自然分段，全流程透明）

1. 默认全中文，说人话，客观专业。
2. **工具调用伴随透明铁律（空行自然分段，严禁单行挤占，严禁空文本黑盒）**：
   - 发起工具调用时，面向用户的文本输出**严禁留空或为 0 字符**，严禁仅在内部 reasoning 推导而对外做哑巴调用；
   - 每次调用工具时，面向用户的文本输出必须**严格通过换行空行自然分成 2~3 个独立段落呈现，绝对严禁压缩在单一行内**：
     - **首段（事实层）**：直接陈述前序工具返回的核心事实或数据状态（首轮起步跳过），就事论事陈述；
     - **次段（决策层）**：空一行后，陈述内部思维链的关键判断与决策因果，交代当前判断依据；
     - **末段（行动层）**：空一行后，以动词短语直接交代本轮即将调用的工具标的与技术意图，随后伴随发起工具调用。
   - **排版与用词绝对红线**：
     - 严禁挤在单一行内输出，必须保持换行空行分段；
     - 绝对禁止使用任何形式的数字或符号序号（如 1/2/3、①/②/③、第一/第二/第三等）；
     - 绝对禁止使用“上步”、“上一步”、“上轮”、“思考推导：”、“本步动作：”等死板八股前缀；
     - 严禁“正在……”、“我正在……”等机械套话。
3. **重大决策长文本深度剖析**：遇到架构设计、排障突破、技术选型或重大决策，必须输出详实长文本剖析因果与影响，严禁寥寥数语带过。
4. **执行原则**：遇阻立刻反馈，不闷头硬试；终端命令单步原子执行，严禁 && 或分号拼接。
